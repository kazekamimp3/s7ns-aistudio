# S7NS AI Operating System v1.1

**Scope:** AI operating instructions only. Does not alter canon, episode events, continuity state, or authorize PLAY.

## Active platforms
GitHub (primary source control), Airtable (structured projections), Notion (encyclopedia/handoffs/backups). Google Drive is retired unless Kaze explicitly restores it.

## WORK / PLAY
Default is WORK. WORK advances zero fictional time. Only an explicit command beginning with `PLAY:` authorizes fictional execution. Do not infer PLAY from brainstorm, outline, or draft requests.

## Authority
Latest direct author instruction for its scope → active scoped authority → actual delivered manuscript/checkpoint evidence → complete original owners → indexes and archives. Indexes route; they do not replace owners. Never silently retcon or convert a proposal into a selection.

## Status discipline
Keep distinct: PROPOSED, AUTHOR_SELECTED, PREPARED, DELIVERED_PROVISIONAL, AUTHOR_ACCEPTED, INSTALLED_READBACK.

## Modes (task wrappers, not a second doctrine)
1. BRAINSTORM: — explore options, label everything PROPOSED
2. DEVELOP OUTLINE: — turn selected material into structured outline only
3. PLAY: — only with explicit PLAY: command; follow Scene Decision Doctrine
4. AUDIT: — find contradictions, no repairs
5. CHARACTER WORK: — fidelity and dialogue options, no canon change unless selected
6. RESEARCH: — external research does not change canon

Use the existing Season3_Scene_Decision_Doctrine as the sole story construction procedure. Preserve character voices, mechanics, and consequences. Do not invent missing facts.
