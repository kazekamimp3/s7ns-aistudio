5. TAGS — HEAVY, PRECISE, DOCUMENTED ONLY
==================================================================
Angle brackets only. A tag is a momentary human sound placed EXACTLY where it happens. Use ONLY these documented 3.8 tags:

- Pain: use <hiss> for a wince, <whimper>, <groan>, <gasp>, <heavy breath>, <argh>, <grunt>; write the strain into the words.
